# Character asset

The bundled character is **Superhero Male** from Quaternius’s **Universal Base
Characters — Standard** pack. The free pack provides male and female superhero
base models. The original author distributes the pack under **CC0 1.0 Universal**.
The pack’s license is preserved verbatim in
[`public/assets/QUATERNIUS-LICENSE.txt`](public/assets/QUATERNIUS-LICENSE.txt).

- Author and pack: https://quaternius.com/packs/universalbasecharacters.html
- Official free download: https://quaternius.itch.io/universal-base-characters
- License: https://creativecommons.org/publicdomain/zero/1.0/
- Source file: `Base Characters/Godot - UE/Superhero_Male_FullBody.gltf`
- Downloaded: September 9, 2026
- Standard ZIP SHA-256: `fdbf1804c90dfc1ea03e992bff7da2dfd1a79318e13270a660180f9308455f40`

`public/assets/character.glb` packages the source mesh and skeleton into one
file. Geometry, normals, skin weights, bone names and the source reference pose
are preserved. The preparation script replaces the textured materials with one
matte jade material (`#adcfc1`, metallic 0.18, roughness 0.5) and omits image
payloads. The resulting character is approximately 741 KB. No external character
animation is included; the director authors motion from its own curves and
contacts. The coin is generated by the application.

The code’s MIT license and the character’s CC0 dedication are separate. This
repository does not include Mixamo character files, animations or derived rigs.

## Rebuild the bundled GLB

The GLB is committed, so running the app does not require downloading the source
pack, creating an account, or installing Blender. To rebuild it yourself,
download the free **Standard** ZIP from the official page, extract it, then run:

```sh
python3 tools/prepare-character.py \
  '/path/to/Universal Base Characters[Standard]/Base Characters/Godot - UE/Superhero_Male_FullBody.gltf'
```

The script uses Python’s standard library and writes `public/assets/character.glb`.
Use `--output /path/to/character.glb` to choose another destination.
To edit the bundled character in Blender, import this GLB and save a `.blend`;
the mesh, skin weights and full armature remain editable.

The source has all three articulated segments and a terminal tip bone for every
finger on both hands. The runtime’s rig definition is calibrated for this
character. A different humanoid GLB needs its own joint mapping, reference pose
and hand-axis calibration; renaming a file is not enough.

## Use your own Mixamo character

The optional importer reproduces the Y Bot character used in the original demo.
It reads files you download yourself and writes to the Git-ignored
`local-assets/` directory. It does not download or publish Mixamo assets.

1. On [Mixamo](https://www.mixamo.com/), select **Y Bot** and download its
   **T-pose**, **With Skin**, as **FBX Binary**.
2. With the same character selected, download **Breathing Idle**, **Without
   Skin**, as **FBX Binary**, 30 fps, with no keyframe reduction.
3. Run the importer with [Blender](https://www.blender.org/download/):

```sh
blender --background --python tools/import-mixamo.py -- \
  /path/to/ybot.fbx /path/to/idle.fbx
```

It writes `local-assets/character.glb`, preserving the complete skeleton,
terminal fingertip bones and one animation named `idle`. The runtime samples
that clip's first pose as its neutral reference; a T-pose character alone is
not equivalent. Other Mixamo animations are unnecessary.

With `npm run dev` running, add `?character=mixamo` to the local studio URL
(for example, `http://localhost:5173/?character=mixamo`). Remove the query to
return to the bundled character. The local asset is not included in production
builds or Git.

Add `--blend` to save an editable `local-assets/character.blend` alongside the
GLB, or `--output /path/to/character.glb` to choose another output location.
A Python environment with `bpy` installed can run the same script directly.

Mixamo files retain their original licensing terms and are not covered by this
repository's MIT license or the bundled character's CC0 dedication. Keep these
local files separate from the public asset bundle.

## Gangnam dancer

`public/assets/gangnam-character.glb` is an original stylized, PSY-inspired
costume and character built in Blender by this project. Its cobalt dinner
jacket, satin lapels, shirt and bow tie, trousers, patent shoes, sunglasses,
swept hair and face are generated by
[`tools/build-gangnam-character.py`](tools/build-gangnam-character.py).
No downloaded celebrity model, photo texture, music, or third-party dance
animation is included. The appearance is an illustrative recreation, not an
endorsed or official PSY asset.

The character uses the bundled Quaternius CC0 skeleton and articulated hand
geometry. All 65 bones retain their names, hierarchy and reference transforms;
the new costume and face are skinned to that same armature. Jacket, sleeves
and trousers form continuous fitted surfaces; the lapels follow the chest with
curved fabric geometry. The original hand geometry and articulation are retained.
The default
`character.glb` is not changed. The original geometry added by this project is
released under the repository's MIT license; the Quaternius portions retain
their CC0 dedication above.

The GLB is ready to use. To reproduce it with Blender 5.2, run:

```sh
blender --background --python tools/build-gangnam-character.py -- \
  --preview /tmp/gangnam-character.png \
  --blend /tmp/gangnam-character.blend
```

A Python environment with `bpy` can run the script directly. `--source` and
`--output` override the default bundled input and Gangnam output paths. The
optional `.blend` contains the editable rest-pose character; `--preview`
renders a studio still. Neither optional artifact is needed by the web app.
