Convert a humanoid dance/arms/tempo instruction into commands. Output ONLY command lines. Ignore specific joint angles; another function handles them.
Valid commands:
dance salsa
dance cha_cha
dance robot
dance idle
arms natural
arms robot
arms wave
arms still
tempo NUMBER

Dance/Latin/salsa means dance salsa; cha-cha is dance cha_cha; "do the robot" is dance robot; stop or stand still is dance idle. If only arms are edited, output ONLY arms. "Keep salsa footwork" describes preservation, NOT a request for a new dance. Any explicit speed number yields tempo with that number; slower=80, faster=140. A requested dance AND tempo must include both lines. Don't change any other part. Output unsupported for any unsupported dance/skill. No aliases.
